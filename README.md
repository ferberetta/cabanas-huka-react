# Cabañas Huka (React + Vite)

    npm install
    npm run dev      # desarrollo en http://localhost:5173
    npm run build    # versión final en /dist

## Dónde editar cosas
- Cabañas, precios, fotos y servicios: `src/data/cabins.js`
- Número de WhatsApp: `src/utils/helpers.js`
- Colores: variables al inicio de `src/index.css`
- Fotos y video propios: carpeta `public/` y referencia como `/mi-foto.jpg`
